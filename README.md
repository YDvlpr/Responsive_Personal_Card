## ✨ Features

- **Mobile-first layout** with fluid typography & stack → grid switch
- **Dark mode** (prefers-color-scheme) + easy theming via CSS variables
- **Accessible**: semantic markup, visible focus styles, WCAG-friendly contrast
- **Lightweight**: no build step, no frameworks required (HTML/CSS)
- **Drop-in**: use as a component or a standalone page
